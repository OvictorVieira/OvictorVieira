# Domain Terms

- **Profile repository:** A repository whose name matches its GitHub owner and whose README is rendered on that owner's profile.
- **Metrics:** Generated visual summaries of GitHub and WakaTime activity.

## Technical Terms and Acronyms

- **SVG:** Scalable Vector Graphics, the generated image format.
- **API:** Application Programming Interface used to retrieve activity data.
- **Workflow:** GitHub Actions automation defined under `.github/workflows/`.

## Naming Conventions

- Generated metric assets live in `metrics/` and use descriptive lowercase names.
- Workflow files use lowercase kebab-case names.
